# Veterinary Clinic Simulation

A clinic scheduling and simulation system written in C that models patient arrivals, treatment queues, and exposure tracking using custom data structures.

## Features

- Event-driven clinic simulation
- Queue-based patient scheduling
- Stack-based exposure tracking
- Sorted arrival processing
- Dynamic memory management
- File input processing
- Multi-doctor treatment workflow

## Concepts Used

- Linked Lists
- Queues
- Stacks
- Dynamic Memory Allocation
- File I/O
- Event Simulation
- Algorithm Design

## Technologies

- C
- GCC
- Command Line

## Files

- pa3.c - Main application

## What I Learned

This project strengthened my understanding of dynamic data structures, memory management, queue and stack implementations, and event-driven simulation systems.
